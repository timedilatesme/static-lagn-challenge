--- METADATA & GEOMETRY --------------------------------------------------------
Lens ID        : Unique standardized identifier.
                 Format: D1_L000YYYYY (where YYYYY is a 0-padded index)
                 Example: 'D1_L00000001' for SLSim "D1" and "L" for lens system
RA             : Right Ascension in decimal degrees, uniformly randomized over 
                 the LSST footprint (0 to 360).
Dec            : Declination in decimal degrees, uniformly randomized over 
                 the LSST footprint (-72 to +12).
num_images     : Number of lensed images produced by the system.
                 Example: 2 for doubles, 4 for quads.

--- DEFLECTOR MASS (LENS GALAXY) -----------------------------------------------
zlens          : Redshift of the deflector galaxy.
vel_disp       : Velocity dispersion of the deflector mass profile in km/s.
ell_m          : Total ellipticity amplitude of the deflector mass profile.
ell_m_PA       : Position angle of the mass profile ellipticity in degrees.
sh             : External shear amplitude affecting the system.
sh_PA          : Position angle of the external shear in degrees.
Rein           : Einstein radius of the lensing system in arcseconds.

--- DEFLECTOR LIGHT (LENS GALAXY) ----------------------------------------------
ell_l          : Total ellipticity amplitude of the deflector light profile.
ell_l_PA       : Position angle of the light profile ellipticity in degrees.
Reff_l         : Effective (half-light) radius of the deflector in arcseconds.
n_l_sers       : Sérsic index of the deflector galaxy light profile.
mag_lens_{b}   : Apparent magnitude of the deflector galaxy in band {b}.
                 Dynamic columns created for each band in all_bands.
                 Examples: mag_lens_g, mag_lens_r, mag_lens_i, mag_lens_z, mag_lens_y

--- SOURCE PROPERTIES (EXTENDED HOST GALAXY) -----------------------------------
zsrc           : Redshift of the background source galaxy.
srcx           : Unlensed x-position center of the extended source (arcsec).
srcy           : Unlensed y-position center of the extended source (arcsec).
ell_s          : Total ellipticity amplitude of the unlensed source galaxy.
ell_s_PA       : Position angle of the source ellipticity in degrees.
Reff_s         : Effective (half-light) radius of the unlensed source (arcsec).
n_s_sers       : Sérsic index of the source galaxy light profile.
mag_src_{b}    : Apparent magnitude of the unlensed extended source in band {b}.
                 Dynamic columns created for each band in all_bands.
                 Examples: mag_src_g, mag_src_r, mag_src_i, mag_src_z, mag_src_y

--- POINT SOURCE / AGN PROPERTIES (UNLENSED) -----------------------------------
psx            : Unlensed x-position of the point source / AGN (arcsec).
psy            : Unlensed y-position of the point source / AGN (arcsec).
bh_mass_exp    : Black hole mass exponent (i.e., log10(M_BH/M_sun)).
edd_ratio      : Eddington luminosity ratio of the AGN (dimensionless).
dt_max         : Maximum time delay between any pair of lensed images (days).
mag_ps_{b}     : Apparent magnitude of the unlensed point source in band {b}.
                 Dynamic columns created for each band in all_bands.
                 Examples: mag_ps_g, mag_ps_r, mag_ps_i, mag_ps_z, mag_ps_y

--- LENSED POINT SOURCE IMAGE PROPERTIES ---------------------------------------
Note: N goes from 1 to max_num_images (default 5). Filled with np.nan if image index > num_images.

dt_days_{N}    : Arrival time delay for image {N} relative to start (days).
                 Example: dt_days_1 = 0.0, dt_days_2 = 12.4
mu_{N}         : Magnification (amplification factor) for image {N}.
                 Example: mu_1 = 4.25, mu_2 = -2.10
x_img_{N}      : Observed x-coordinate position of image {N} (arcseconds).
                 Example: x_img_1 = 1.12
y_img_{N}      : Observed y-coordinate position of image {N} (arcseconds).
                 Example: y_img_1 = -0.45
mag_ps_img_{b}_{N} : Apparent magnitude of lensed point source image {N} in band {b}.
                     Dynamic columns per band per image number.
                     Examples: mag_ps_img_g_1, mag_ps_img_r_1, mag_ps_img_g_2, mag_ps_img_r_2
